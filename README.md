# PortReady AI — Maritime Readiness Workflow Prototype

**Project Context:** Manager-assigned software engineering project developed during my work at LISCR.

PortReady AI is a Java Spring Boot and React application designed to demonstrate maritime readiness workflows, including vessel arrival tracking, certificate monitoring, inspection finding management, and rule-based prioritization.

The current implementation is a prototype using fictional demonstration data and illustrative workflow rules. It is not a production compliance system or an official maritime safety assessment.

**Confidentiality:** This repository is maintained privately. Its contents are not intended for public distribution without appropriate authorization.
